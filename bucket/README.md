# Scoop bucket for kalide

This directory is the Scoop manifest for `kalide`, hosted in the source repo.
Install it anonymously — no GitHub account or token is needed:

```
scoop bucket add kalide https://github.com/really-knows-ai/kalide
scoop install kalide
```

Update later with:

```
scoop update kalide
```

`INSTALL.md` documents this in plain language for non-developers.

## Manifest shape

`bucket/kalide.json` is a standard Scoop manifest. Each architecture entry has
the public release-download `url` (renamed to `kalide.exe` via `#/kalide.exe`)
and its SHA-256 `hash`; Scoop downloads and verifies it itself, and `bin` shims
`kalide.exe` as `kalide`.

## Architectures

- `architecture.64bit` → `kalide-windows-amd64.exe`. Always present.
- `architecture.arm64` → `kalide-windows-arm64.exe`. Present **only when that
  target was released**; the release workflow adds the arm64 block for releases
  that shipped a windows/arm64 binary and removes it otherwise.

## Fields regenerated by the release workflow

The `release.yml` manifest job rewrites these from the pushed `vX.Y.Z` tag and
the release's `checksums.txt`:

| Field | Regenerated from |
|---|---|
| `version` | the pushed `vX.Y.Z` tag |
| `architecture.64bit.url` / `.hash` | the tag / `checksums.txt` |
| `architecture.arm64.url` / `.hash` | the tag / `checksums.txt`, when released |

The job commits only files under `Formula/` and `bucket/` and never creates
tags.

## Validating

```
python3 -m json.tool bucket/kalide.json
```

(or `jq . bucket/kalide.json`).
